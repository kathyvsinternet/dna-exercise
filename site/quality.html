Quality

What was wrong, and what the build now refuses

The raw files stay untouched in data/raw/. python pipeline/build.py applies these treatments and stops before writing the model if a check fails. The longer write-up is in data/quality/issues/.

Duplicate users

806 user rows, 800 distinct ids. Six ids were repeated, and each pair matched on every column.

Treatment. Keep the first row. dim_user has 800 rows.

Check. Fail if a user id is repeated. Fail if a new pair disagrees on any column, instead of picking a winner silently.

Test accounts and sentinel values

40 users are flagged as test accounts. They account for 39 subscriptions and 308 events. Planted tokens such as carrier_pigeon, TEST_TYPE, TEST_STATUS_DO_NOT_USE, and glitch_in_the_matrix also appear on rows that are not test accounts.

Treatment. Keep the rows. Marts and metrics leave test accounts out. Planted tokens become unknown on the governed column, and the original stays in a raw column. Fictional countries and lifetime_deal_fake stay as they are.

Check. Fail if a metric is built from a test account, or if a governed column still contains a planted token.

Missing foreign keys

195 of 300 content items have a blank creator. That is every PageGarden and GatherSquare item. Every MakerHarbor item has one. 323 of 6,000 events have a blank content id, and those blanks are the search, page-view, and subscription events, plus two glitch events. No row points at an id that does not exist.

Treatment. Keep the row and store a null key. Do not invent a creator or a title.

Check. Fail on a dangling key. Fail if MakerHarbor content loses its creator, if a search or subscription event gains a content id, or if an open, complete, like, share, comment, or download loses one.

Invalid measures

A few measures use sentinel numbers: runtime -1 and 99999 (10 rows), followers -5 and 999999 (4), price -9.99 and 999.99 (16), and session length -15, exactly 24 hours, or exactly 7 days (64).

Treatment. Keep the row. Null the governed measure, keep the source number, and set an invalid flag. Counts still include the row. Sums do not.

Check. Fail if a governed measure is still negative or still holds one of those sentinels.

Blank subscription fields

215 subscriptions are Free, have a blank billing cycle, and have a zero price. Those are the same 215 rows. End date is blank for every status except canceled. All 224 canceled subscriptions have an end date, and none ends before it starts.

Treatment. Free billing cycle becomes not_applicable. A blank end date stays null and is valid unless the raw status is canceled.

Check. Fail if a Free plan has a price or a raw billing cycle. Fail if a paid plan is blank or zero. Fail if a canceled plan has no end date.

The checks live in pipeline/checks.py. The classified values live in pipeline/rules.py.
